Course project · Control theory

Quarter-car active suspension study

Advanced Control Theory course project, simulation only. It reproduces Na et al. (IEEE TSMC 2022) approximation-free active suspension control in MATLAB/Simulink: after fitting two plant parameters to the paper's Case-10 experiment, the unchanged controller lands within about 6% of its error indices (IAE 0.129 vs 0.122). It then tests the claims: the paper's Case-B gains fail a hold-out test, LQR and skyhook baselines match or beat it at equal effort, and an anti-windup extension keeps the wheel on the road over a 50 mm bump.

MATLAB · Simulink · C port timed for a Cortex-M4 · FreeCAD rig · browser lab

Contributor - Inspect Robots

2026

Robocurve (YC S26) builds open-source tools and independent benchmarks for physical AI. Inspect Robots is its MIT-licensed evaluation framework; its CI gates merges on 100% core test coverage, strict mypy, and ruff. / 2 merged PRs / 3 open / author of inspect-robots-wandb on PyPI

Contribution log
  • inspect-robots-wandb v0.1.0 · published on PyPI · source — Weights & Biases logging sink shipped as a standalone package after the maintainers asked for W&B support to live outside the core. Each evaluation becomes one W&B run with the full eval spec as config plus status, trial counts, errored trials, steps, duration, and every aggregate metric. Registers through plugin entry points, 100% coverage, CI on Python 3.10 to 3.13, PyPI trusted publishing.
  • PR #476 · merged · issue #441 — Exposed max_retries and backoff_s on the LLM agent policy across five wire protocols; HTTP retries honor Retry-After (seconds and HTTP-date) with exponential backoff fallback, and the effective settings are recorded in the eval log.
  • PR #475 · merged · issue #473 — Eval logs recorded a bare commit SHA when git status failed, making an unknown working tree look clean; now records unknown provenance, with a regression test.
  • PR #514 · open, in review · issue #136 — Checkpoint and resume for long eval sets on robot hardware: single-writer manifest with input identity checks, immutable per-attempt logs, in-flight markers that block ambiguous replay, retries only for recoverable policy errors (safety aborts and hardware faults stop the run), and atomic writes. New eval-set --checkpoint flag.
  • PR #550 · open — Optional on_eval_error sink hook so sinks holding remote state can clean up when an evaluation aborts; never masks the original exception, notifies each started sink at most once.
  • PR #551 · open — Community plugins section in the plugin guide, listing inspect-robots-wandb.
  • PR #434 · closed by agreement — Original in-repo W&B sink; reviewed as well put together, then split into the external package, #550, and #551.
